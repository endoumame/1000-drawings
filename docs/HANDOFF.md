# 1000体ドローイング 引き継ぎ資料

人体ドローイングの練習記録をつける PWA。モックアップのレビューが終わり、仕様とデザインが固まった状態から実装を始めるための資料。

- モックアップ（操作できる版）：https://claude.ai/artifact/RnugWne58EhCnJvAz1mTJW
- モックアップのソース：[`docs/mockup/Main.dc.html`](mockup/Main.dc.html)（デザイン用ツールの形式。見た目と挙動の参照用で、そのまま動かすものではない）

## 目的

- 絵の練習で毎日人体を描いている。目標は1000体。
- **一番の目的はモチベーションを保つこと。** 残りの数が減っていくのが見えて、記録が苦にならないことを優先する。
- 利用者は1人（開発者の親友）。スマホのホーム画面に追加して使う。

## 仕様

### 種類

- 「30秒ドローイング」と「90秒ドローイング」の2種類。増える予定はない。
- 画面上部のタブで切り替える。ホームと履歴の両方にタブがある。
- **種類ごとにそれぞれ1000体からカウントダウンする。**

### ホーム

- 大きなカードに「◯秒ドローイング ゴールまで」と残り体数（1000 − その種類の合計）を大きく表示する。
- その下に進み具合のバー、「描いた数 ◯ / 1000」、「今日 ◯ 体」を表示する。
- 100体ごとの節目までの残りを表示する（例：「次の節目 200体まで、あと10体」）。達成したら「1000体達成！ほんまにおつかれさま。」と出す。
- 「最近の記録」に直近3日分を表示する。1行に日付、その日の合計、「◯回に分けて」を出す。今日の行は日付の前に「今日」をつける。
- 「すべて見る」から履歴画面へ移る。

### 追加

- 右下の「＋ 描いた」ボタンで、下から追加シートを開く。
- 記録先は**開いているタブの種類**。シートの見出しも「30秒ドローイングを追加」のように種類名を出す。
- 数は −／＋ ボタン（最小1）と、＋1・＋5・＋10・＋20 のボタンで入れる。初期値は10。
- 日付と時刻を指定できる。初期値は今の日時。
- **同じ日に何回追加しても、その日の合計に足される。** シートには記録する前に「10/20（火）は 50体 → 60体 にプラスされます」と結果を出す。その日の記録がまだなければ「◯の記録として新しく追加されます」と出す。
- 記録したら上部に短い通知を出す（例：「30秒 +10体！ 10/20（火）は合計60体になりました」）。2.6秒ほどで消える。

### 履歴

- その種類の合計、描いた日数、1日平均を3つ並べて出す。
- 日ごとに1枚のカードで、日付と合計を出す。カードの中に「08:10 +20」のように1回ごとの内訳を小さく並べる。
- 新しい日付が上。

### 編集と削除

- 記録を間違えたときのために、1回ごとの記録を編集と削除できるようにする。
- 履歴画面の内訳（「08:10 +20」など）から選んで、数、日付、時刻を直せる。
- 削除する前に確認を出す。
- 編集や削除をしたら、その日の合計と残り体数に反映する。
- 画面のデザインはモックアップにないので、追加シートと同じ見た目に合わせて作る。

### データの持ち方

1回の追加ごとに次の形で保存し、表示するときに日ごとに合計する。

```js
{ id, mode: '30' | '90', date: 'YYYY-MM-DD', time: 'HH:MM', count: number, createdAt }
```

- 日付は端末の現地時刻で扱う。
- 利用者は1人なので、保存先はブラウザ内（IndexedDB または localStorage）で足りる想定。

## デザイン

モックアップの見た目に合わせる。レイアウトと形は nani.now を参考にしたもの、色とフォントは独自のもの。

### フォント（Google Fonts）

- 本文と日本語：Zen Kaku Gothic New（400 / 500 / 700）
- 数字（残り体数、合計、履歴の数など）：DM Serif Display（400）
- 残り体数は 112px、字間 -0.02em。

### 色

| 用途 | 値 |
| --- | --- |
| 背景 | `#F6F3EC`（`#E4DED2` の 1.2px のドットを 18px 間隔で敷く） |
| カード | `#FFFFFF` |
| 文字 | `#1F1D1A` |
| 補助の文字 | `#5E5850`、`#4A453E` |
| 枠線、バーの下地 | `#E4DED2` |
| 強めの枠線 | `#D5CEC0` |
| タブの下地 | `#EAE4D8` |
| 内訳のチップ | `#F1ECE2` |
| 30秒の色 / 薄い色 | `#2F6B66` / `#E3EEEC` |
| 90秒の色 / 薄い色 | `#B4532F` / `#F6E6DF` |

種類の色は、進み具合のバー、「＋ 描いた」と「記録する」のボタン、選択中のタブの文字、節目の表示、＋1〜＋20 のボタンに使う。

### 形

- 大きなカードの角丸は 24px、記録の行は 18px、履歴の数字カードは 16px、追加シートの上の角は 32px。
- ボタンはほぼ丸い形（`border-radius: 999px`）。
- カードの影：`0 2px 3px -1.5px rgba(31,29,26,0.05), 0 12px 32px -18px rgba(31,29,26,0.18)`
- 浮いたボタンの影：`inset 0 1px 0 rgba(255,255,255,0.3), 0 2px 4px rgba(31,29,26,0.15), 0 7px 19px rgba(31,29,26,0.25)`
- 押せる場所は 44px 以上。アイコンは線の SVG を使い、絵文字は使わない。

## 公開

- GitHub Pages で公開する。URL は `https://endoumame.github.io/1000-drawings/` になる想定。
- サイトがドメインの直下ではなく `/1000-drawings/` の下に置かれるので、マニフェストの `start_url` と `scope`、サービスワーカーの登録範囲、読み込むファイルのパスをそれに合わせる。

## データの書き出しと読み込み

- 記録は端末のブラウザの中にしか残らないので、機種変更やブラウザのデータ消去に備えて、設定画面から全記録をファイルに書き出せるようにする。
- 書き出したファイルを読み込むと、今の記録と置き換える。置き換える前に確認を出す。

## 使う技術

- フレームワークは使わない。Vite と TypeScript で作り、テストは Vitest で書く。
- 日ごとの合計や残り体数の計算など、画面に依存しない部分はテストを先に書いて作る。
